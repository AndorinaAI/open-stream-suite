## Contents
| File | Purpose |
| :--- | :--- |
| `install.command` | Installs dependencies (`app/venv/`) |
| `Iniciar Open Stream Suite.command` | Starts the suite |
| `update.command [branch]` | Updates via Git (`main` or `dev`) |

## Steps
1. Requirements: `brew install python python-tk`
2. Install: double-click `install.command`
3. Start: double-click `Iniciar Open Stream Suite.command`

If macOS blocks the scripts: `chmod +x Mac/*.command`.
