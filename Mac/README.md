## Contenido
| Archivo | Función |
| :--- | :--- |
| `install.command` | Instala dependencias (`app/venv/`) |
| `Iniciar Open Stream Suite.command` | Inicia la suite |
| `update.command [rama]` | Actualiza vía Git (`main` o `dev`) |

## Pasos
1. Requisitos: `brew install python python-tk`
2. Instalar: doble clic en `install.command`
3. Iniciar: doble clic en `Iniciar Open Stream Suite.command`

Si macOS bloquea los scripts: `chmod +x Mac/*.command`.
