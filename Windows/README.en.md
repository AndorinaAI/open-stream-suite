## Contents
| File | Purpose |
| :--- | :--- |
| `install.bat` | Installs dependencies (`app\venv\`) |
| `Iniciar Open Stream Suite.bat` | Starts the suite |
| `update.bat [branch]` | Updates via Git (`main` or `dev`) |

## Steps
1. Requirements: Python 3.10+ from [python.org](https://www.python.org/) with **Add Python to PATH** checked.
2. Install: double-click `install.bat`
3. Start: double-click `Iniciar Open Stream Suite.bat`
