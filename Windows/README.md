## Contenido
| Archivo | Función |
| :--- | :--- |
| `install.bat` | Instala dependencias (`app\venv\`) |
| `Iniciar Open Stream Suite.bat` | Inicia la suite |
| `update.bat [rama]` | Actualiza vía Git (`main` o `dev`) |

## Pasos
1. Requisitos: Python 3.10+ desde [python.org](https://www.python.org/) marcando **Add Python to PATH**.
2. Instalar: doble clic en `install.bat`
3. Iniciar: doble clic en `Iniciar Open Stream Suite.bat`
