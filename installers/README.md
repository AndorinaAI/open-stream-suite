👉 Para la guía completa detallada, consulta: **[INSTALACION_E_INICIO.md](../app/docs/INSTALACION_E_INICIO.md)** ([English](../app/docs/INSTALLATION_AND_STARTUP.md)).

> [!NOTE]
> Desarrollamos principalmente en **GNU/Linux**. Los instaladores para Windows y macOS son funcionales, pero al no usar esos sistemas privativos en el día a día, ¡agradecemos todo vuestro feedback y reportes en GitHub Issues!
