## Contents
| File | Purpose |
| :--- | :--- |
| `install.sh` | Installs dependencies (`app/venv/`) and creates the menu shortcut |
| `Iniciar Open Stream Suite.sh` | Starts the suite |
| `update.sh [branch]` | Updates via Git (`main` or `dev`) |
| `open-stream-suite.desktop` | Desktop shortcut |

## Steps
1. Requirements: `sudo apt install python3 python3-venv python3-tk`
2. Install: `./Linux/install.sh`
3. Start: `./Linux/Iniciar\ Open\ Stream\ Suite.sh` (or from your application menu)
