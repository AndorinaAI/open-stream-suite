## Contenido
| Archivo | Función |
| :--- | :--- |
| `install.sh` | Instala dependencias (`app/venv/`) y crea el acceso directo en el menú |
| `Iniciar Open Stream Suite.sh` | Inicia la suite |
| `update.sh [rama]` | Actualiza vía Git (`main` o `dev`) |
| `open-stream-suite.desktop` | Acceso directo de escritorio |

## Pasos
1. Requisitos: `sudo apt install python3 python3-venv python3-tk`
2. Instalar: `./Linux/install.sh`
3. Iniciar: `./Linux/Iniciar\ Open\ Stream\ Suite.sh` (o desde el menú de aplicaciones)
