## Reporting a vulnerability
**Do not open a public issue.** Use
[GitHub private vulnerability reporting](https://github.com/AndorinaAI/open-stream-suite/security/advisories/new).

We aim to reply within 7 days.

## Good practices
- Never share `app/.env`, `app/.local_token`, `client_secret` or Streamlabs tokens.
- The server listens only on `localhost` by default.
