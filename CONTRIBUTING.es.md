# Contribuir

[English](CONTRIBUTING.md) · **Español**

¡Gracias por querer mejorar Open Stream Suite!

## Ramas
- `main`: estable
- `dev`: desarrollo; abre tus PRs contra `dev`

## Flujo de trabajo
1. Haz un fork y crea una rama `feat/...`, `fix/...` o `docs/...`.
2. Usa [Conventional Commits](https://www.conventionalcommits.org/es/) (`feat:`, `fix:`, `docs:`, `chore:`).
3. Abre un PR contra `dev` rellenando la plantilla.
4. **Nunca** incluyas tokens, archivos `.env` ni datos personales.

El idioma principal de este repositorio es el **inglés**, y el español es el idioma secundario.

Lee también el [Código de Conducta](CODE_OF_CONDUCT.es.md) y [SECURITY.es.md](SECURITY.es.md).
