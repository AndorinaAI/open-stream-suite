# Contributing

**English** · [Español](CONTRIBUTING.es.md)

Thanks for helping improve Open Stream Suite!

## Branches
- `main`: stable
- `dev`: development; open your PRs against `dev`

## Workflow
1. Fork the repo and create a `feat/...`, `fix/...` or `docs/...` branch.
2. Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `chore:`).
3. Open a PR against `dev` and fill in the template.
4. **Never** include tokens, `.env` files or personal data.

The primary language of this repository is **English**. Please write issues, PRs and docs in English.

Please also read the [Code of Conduct](CODE_OF_CONDUCT.md) and [SECURITY.md](SECURITY.md).
