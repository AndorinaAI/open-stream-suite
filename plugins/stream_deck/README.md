# 🎮 ELGATO STREAM DECK — PLUGIN OFICIAL OPEN STREAM SUITE
### Control Hardware con Feedback Bidireccional en Pantallas LCD

<p align="center">
  <b>Español</b> | <a href="README.en.md">English</a>
</p>

Este plugin permite controlar toda la suite de Open Stream Suite desde cualquier consola Elgato Stream Deck (Mini, Standard de 15 teclas, XL de 32 teclas, Stream Deck + o Stream Deck Mobile).

---

## 🚀 Instalación en 1 Clic

### En Windows:
1. Copia la carpeta `com.openstreamsuite.deck.sdPlugin` en:
   ```
   %appdata%\Elgato\StreamDeck\Plugins\
   ```
   *(Ruta completa habitual: `C:\Users\<TuUsuario>\AppData\Roaming\Elgato\StreamDeck\Plugins\`)*
2. Reinicia la aplicación **Stream Deck**.

### En macOS:
1. Copia la carpeta `com.openstreamsuite.deck.sdPlugin` en:
   ```
   ~/Library/Application Support/com.elgato.StreamDeck/Plugins/
   ```
2. Reinicia la aplicación **Stream Deck**.

---

## 🌟 Acciones Disponibles en el Panel de Elgato

Una vez instalado, verás la categoría **Open Stream Suite** con las siguientes acciones:

1. **Disparar Meme / Trigger**:
   * Asigna el ID del meme (por ejemplo `susto`, `aplausos`, etc.). Al pulsar la tecla, el meme saldrá en pantalla en OBS.
2. **Aplicar Paleta de Tema**:
   * Cambia el color neón global en vivo (`maker`, `print`, `cyberpunk`, `golden_glory`, `chill`).
   * La tecla se actualiza automáticamente mostrando el tema activo.
3. **Temporizador Open Stream Suite (Feedback en Pantalla LCD)**:
   * Muestra la cuenta atrás en tiempo real en la pantalla del botón.
   * Con un toque inicia; con otro pausa o resetea.
4. **Lluvia de Emotes / Confeti**:
   * Explosión interactiva de confeti o corazones en la pantalla de OBS.
