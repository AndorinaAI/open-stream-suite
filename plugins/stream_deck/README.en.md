# 🎮 ELGATO STREAM DECK — OFFICIAL OPEN STREAM SUITE PLUGIN
### Hardware Control with Two-Way Live Feedback on LCD Keys

  <a href="README.md">Español</a> | <b>English</b>
</p>

This plugin enables direct control of Open Stream Suite from any Elgato Stream Deck console (Mini, 15-key Standard, 32-key XL, Stream Deck +, or Stream Deck Mobile).

---

## 🚀 1-Click Installation

### On Windows:
1. Copy the `com.openstreamsuite.deck.sdPlugin` directory into:
   ```text
   %appdata%\Elgato\StreamDeck\Plugins\
   ```
   *(Standard path: `C:\Users\<User>\AppData\Roaming\Elgato\StreamDeck\Plugins\`)*
2. Restart the **Stream Deck** application.

### On macOS:
1. Copy the `com.openstreamsuite.deck.sdPlugin` directory into:
   ```text
   ~/Library/Application Support/com.elgato.StreamDeck/Plugins/
   ```
2. Restart the **Stream Deck** application.

---

## 🌟 Available Actions in the Elgato Library

Once installed, you will see the **Open Stream Suite** category:

1. **Trigger Meme / Sound**:
   * Set the meme ID (e.g. `susto`, `applause`, etc.). Tapping the key renders the video/sound in OBS.
2. **Apply Color Theme**:
   * Change the global neon palette live (`maker`, `print`, `cyberpunk`, `golden`, `chill`).
   * The LCD button updates dynamically showing the active theme.
3. **Countdown Timer (LCD Countdown)**:
   * Displays the remaining countdown in real-time on the button display.
   * Tap to start, tap again to pause or reset.
4. **Confetti / Emote Shower**:
   * Triggers an interactive explosion of confetti or hearts across OBS.
